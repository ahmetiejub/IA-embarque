Une carte STM32N6 mesure la température, l'humidité et la pression, et un réseau de neurones exécuté sur la carte devine le temps qu'il fait. Le même modèle tourne aussi dans le Cloud (MATLAB). Cette page compare en direct les deux réponses avec la vraie météo.

Comment ça marche

  1. 1. MesureCapteurs SHT40 et LPS22HH sur une carte NUCLEO-N657X0-Q (Cortex-M55).
  2. 2. IA sur la carteRéseau de neurones 12 → 32 → 16 → 5 exécuté en C en ≈ 5,6 ms, sans Internet.
  3. 3. IA dans le CloudLes mesures partent sur ThingSpeak ; MATLAB les classe avec le même modèle ONNX.
  4. 4. VérificationLa carte compare sa réponse à la météo réelle d'Open-Meteo et tient un score.
Données : ThingSpeak (mise à jour toutes les 20 s par la carte) et Open-Meteo · Code source : github.com/ahmetiejub/IA-embarque
